# 《漩涡与萤火》视觉小说

> *"九个月的孤独。八千次数据记录。一个不可能的数字。这就是真相降临的方式。"*

改编自原作科幻哲学小说，探讨尺度、意义与存在的交互式视觉小说。

---

## 📖 项目简介

《漩涡与萤火》讲述地质学家Geo Tremor在废弃矿井中发现"负深度"异常信号的故事。当他与被边缘化的天文学家"星图师"联手验证这一发现时，两人揭开了一个关于宇宙本质的惊人真相——地球深处存在巨大漩涡状结构，吸收着地表所有生命的情感和能量。

面对这一发现，玩家将通过一系列关键选择，塑造Geo的性格特质，最终通向7种截然不同的哲学结局。

---

## 🎮 核心特性

### 7种哲学结局
- **A. 宇宙冷漠** - 接受存在的无意义
- **B. 献祭启示** - 以自我牺牲换取理解
- **C. 循环诅咒** - 困于永恒重复的宿命
- **D. 共生启蒙** - 发现与"深层存在"的共生关系
- **E. 觉醒反抗** - 对抗宇宙的寄生结构
- **F. 超越型** - 意识的维度跃迁
- **G. 荒诞接受** - 拥抱不可知的智慧

### 隐藏性格系统
- **接受度** - 对未知的开放程度
- **怀疑度** - 科学理性 vs 神秘主义
- **殉道倾向** - 个体牺牲意愿

玩家的每个选择都会微妙地调整这些维度，最终决定能够触达的结局。

### 独特交互场景
- **数据可视化界面** - 手动调节参数发现"负深度"
- **仪式韵律组合器** - 设计魔法韵律尝试与深层存在沟通
- **学术回忆闪回** - 选择过去的反应，塑造当前性格基线

### 渐进解锁机制
- 第一周目：触达基础认知结局（A/B/G）
- 解锁"星图师日志"：开放时间/共生概念结局（C/D）
- 解锁"禁忌实验"：触达激进路线（E/F）

## 🎵 音频资源需求

详见 [AUDIO_PRODUCTION_GUIDE.md](AUDIO_PRODUCTION_GUIDE.md)

**快速摘要：**
- BGM需求: 主题曲 + 环境音 + 7个结局曲 = 约15-20首
- 音效需求: UI音效 + 场景音效 + 科幻音效 = 约20个
- 配音: 可选，推荐Phase 1无配音，Phase 2考虑关键台词AI配音

**推荐方案（MVP）：**
- 配乐: AI生成（Suno/AIVA）或免费音乐库
- 配音: 无配音 + 情绪音效系统
- 预算: $0-50
