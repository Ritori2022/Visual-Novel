# 《漩涡与萤火》视觉小说改编设计文档

## 项目概述
将原作7结局科幻哲学小说改编为交互式视觉小说，保留原作深度的同时增强玩家代入感。

---

## 核心系统设计

### 1. 隐藏性格量表系统

追踪Geo的三维性格特质（玩家不可见）：

```python
# 性格维度（0-100分值）
acceptance_level = 50      # 接受度：对未知的开放程度
doubt_intensity = 50       # 怀疑度：科学理性 vs 神秘主义
martyrdom_tendency = 50    # 殉道倾向：个体牺牲意愿
```

**性格影响机制：**
- 每个选择调整1-3个维度的±5-15分
- 特定阈值解锁/锁定结局路径
- 性格塑造影响后续可选项的出现

---

### 2. 七结局解锁树状图

```
第一周目可达（基础认知层）：
├─ A. 宇宙冷漠 [acceptance ≥ 60, doubt ≥ 50]
├─ B. 献祭启示 [martyrdom ≥ 70]
└─ G. 荒诞接受 [doubt ≤ 40, acceptance ≥ 55]

解锁"星图师深度对话"后：
├─ C. 循环诅咒 [完成时间异常实验 + doubt ≥ 70]
└─ D. 共生启蒙 [acceptance ≥ 75, doubt 40-60平衡区]

解锁"禁忌实验笔记"后：
├─ E. 觉醒反抗 [martyrdom ≤ 30, acceptance ≤ 40]
└─ F. 超越型 [martyrdom ≥ 60, acceptance ≥ 80]
```

**渐进解锁机制：**
- 第一周目：强制体验A/B/G之一，建立基础世界观
- 完成首次通关：解锁"星图师日志"系统资料
- 达成2个以上结局：解锁"禁忌实验"分支点

### 3. 关键分支点设计

#### 分支点1：发现"负深度"信号后
```
【选择】面对无法解释的数据...
A. "必须找到理性解释" → doubt +10
B. "也许世界本就超出理解" → acceptance +10, doubt -5
C. "这是改写教科书的机会" → 中性，推进主线
```

#### 分支点2：星图师提出联合验证
```
【选择】被学术界抛弃的两个人...
A. "我们互相需要" → martyrdom -5, 开启信任线
B. "只是互相利用" → doubt +8, 冷静线
C. "也许这是命运" → acceptance +7, 神秘线
```

#### 分支点3：可视化实验成功后
```
【选择】看到漩涡吸收生命能量的真相...
A. "必须警告所有小马" → martyrdom +15, 解锁E/F路径
B. "需要更多数据证实" → doubt +10, 科学线
C. "这超出我的理解范畴" → acceptance +12, 哲学线
D. [仅doubt ≥ 60解锁] "也许这只是数据幻觉" → 解锁C循环结局
```

#### 分支点4：仪式设计阶段（核心分歧）
```
【选择】如何与"深层存在"沟通...
A. "用科学频率尝试对话" → 中性，D结局路径
B. "献上自己作为信号" → martyrdom +20, B/F路径
C. "设计反馈循环干扰它" → martyrdom -15, E路径
D. [acceptance ≥ 70] "接受无法沟通的事实" → A/G路径
```

### 4. VN独有交互场景

#### 4.1 数据可视化界面
**场景描述：** Geo在矿井中调试设备
**交互方式：**
- 玩家调节3个参数滑块（频率/深度/灵敏度）
- 不同参数组合触发不同反馈文本
- 特定组合触发"负深度"发现（剧情推进）

**技术实现（Ren'Py）：**
```renpy
screen seismic_interface:
    frame:
        vbox:
            bar value FieldValue(frequency, 100)
            bar value FieldValue(depth, 100)
            bar value FieldValue(sensitivity, 100)

            if frequency > 80 and depth < 20:
                text "检测到异常：负深度信号"
```

#### 4.2 仪式韵律组合
**场景描述：** 设计魔法韵律模式与深层存在沟通
**交互方式：**
- 从6种基础韵律中选择4个组合（次序重要）
- 不同组合对应不同"回应"强度
- 特定组合解锁隐藏CG/文本

**韵律库：**
```
🎵 和谐律（Harmony） - 代表秩序
🎵 混沌律（Chaos） - 代表无序
🎵 上升律（Ascent） - 代表进化
🎵 消解律（Dissolution） - 代表终结
🎵 循环律（Cycle） - 代表轮回
🎵 静默律（Silence） - 代表虚无
```

**特殊组合示例：**
- `和谐→循环→和谐→循环` = 稳定沟通（D结局）
- `上升→上升→上升→消解` = 激进尝试（E结局）
- `静默→静默→静默→静默` = 放弃沟通（A结局）

#### 4.3 学术体制回忆闪回
**场景描述：** Geo回忆被学术界否定的经历
**交互方式：**
- 选择当时的反应（影响当前性格基线）
- 决定创伤深度（影响martyrdom初始值）

**示例选择：**
```
教授当众嘲笑你的理论时，你...
A. "我会证明你们都错了" → doubt +15, martyrdom +10（偏执科学家）
B. "也许他们是对的..." → acceptance -10, doubt -5（自我怀疑）
C. "我只是想找到真相" → 中性（纯粹求知者）
```

### 6. 克拉克硬度滑块系统（可选高级功能）

**概念：** 让玩家调整叙事的"科幻硬度"偏好

**技术实现：**
```renpy
define clarke_index = 50  # 0=神秘主义, 100=硬科幻

# 根据指数切换文本变体
if clarke_index >= 70:
    "传感器检测到时空曲率异常，数值为-3.7西格玛。"
elif clarke_index >= 40:
    "设备显示某种...空间扭曲？数据完全违反常识。"
else:
    "你感受到一股不可名状的力量，仪器只是确认了直觉。"
```

**应用场景：**
- 同一事件的不同文本风格
- 影响星图师的解释倾向
- 调整结局描述的抽象/具体程度

---

### 7. 文本风格指南

**Geo内心独白：**
- 简洁、技术性词汇
- 偶尔流露存在主义思考
- 示例：*"负深度。这个词本身就是悖论。就像'非存在的存在'——但设备不会说谎，除非..."*

**星图师对话：**
- 诗意、隐喻性表达
- 科学与神秘的桥接者
- 示例：*"尺度，Geo。当你测量深渊时，也在被深渊测量。问题不是它在哪里，而是我们够不够格提问。"*

**系统叙述：**
- 冷静、客观的观察者视角
- 重要时刻使用诗意断句
- 示例：*"九个月的孤独。/八千次数据记录。/一个不可能的数字。/这就是真相降临的方式。"*
