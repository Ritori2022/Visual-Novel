## 当前状态

占位符阶段：所有音频文件暂缺
推荐工具：
- 音乐制作：FL Studio / Ableton Live / LMMS（免费）

格式规范：

- 音效: OGG Vorbis, 44.1kHz, 单声道, 质量等级5
- 配音: OGG Vorbis, 44.1kHz, 单声道, 质量等级7
